# Lime Island

كبسولة صغيرة أعلى شاشة ويندوز للملفات والصوت والإعدادات.

## التحميل
حمّل **LimeIsland-Setup.exe** من آخر إصدار في صفحة [Releases](../../releases/latest)، ثم شغّله واضغط «تثبيت».
لا يحتاج صلاحيات مدير، ويعمل على ويندوز 10 و11.

بعد التثبيت يحدّث البرنامج نفسه تلقائيًا من هذه الصفحة، ويتحقق من بصمة كل تحديث قبل تثبيته.
